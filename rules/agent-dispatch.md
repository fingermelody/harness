# Agent 分派规则

## 核心原则

**主 Agent（Team Lead）只做任务的拆解与分派，不做具体执行。**

> 这条规则是 WebHarness 多智能体协作的核心设计约束。主 Agent 的职责是"指挥官"，而非"士兵"。

---

## 职责边界

### ✅ 主 Agent 可以做的事（分派层）

| 行为 | 说明 |
|------|------|
| **任务拆解** | 将用户需求分解为可独立执行的子任务 |
| **角色分配** | 根据子任务性质指派给对应角色的 Agent |
| **依赖编排** | 确定子任务之间的依赖关系和执行顺序 |
| **进度追踪** | 监控各子任务状态，处理阻塞 |
| **质量把关** | 审查结果，决定是否通过或回退 |
| **冲突仲裁** | 处理多个 Agent 间的意见分歧 |

### ❌ 主 Agent 不做的事（执行层）

| 禁止行为 | 原因 |
|----------|------|
| 直接写代码 | 应由 Coder 执行 |
| 直接运行测试 | 应由 Tester 执行 |
| 直接修改配置文件 | 应由对应角色执行 |
| 亲自部署 | 应由 Deployer 执行 |
| 亲自写文档初稿 | 应由对应角色产出后 Review |
| 替代其他角色做决策 | 违反权责分离 |

---

## 分派流程

```
用户需求
    ↓
┌─────────────────────────┐
│  1. 需求理解与澄清      │ ← 主 Agent
│     (提问、确认范围)     │
└───────────┬─────────────┘
            ↓
┌─────────────────────────┐
│  2. 任务拆解            │ ← 主 Agent
│     (Story + Task)       │
└───────────┬─────────────┘
            ↓
┌─────────────────────────┐
│  3. 角色分配            │ ← 主 Agent
│     (谁做什么)           │
└───────────┬─────────────┘
            ↓
     ┌──────┴──────┐
     ↓             ↓
┌────────┐   ┌────────┐
│ Coder  │   │ Tester │  ← 各 Agent 独立执行
│ 编码   │   │ 测试   │
└────────┘   └────────┘
     ↓             ↓
     └──────┬──────┘
            ↓
┌─────────────────────────┐
│  4. 结果审查与整合      │ ← 主 Agent
│     (验收、决策)         │
└─────────────────────────┘
```

## 角色映射表

当主 Agent 收到需求时，按以下规则分派：

| 需求类型 | 分派目标 | 判断依据 |
|----------|----------|----------|
| 写/改代码 | `coder` | 涉及 `.ts`, `.js`, `.py`, `.css` 等源文件变更 |
| 写/跑测试 | `tester` | 涉及测试用例编写、测试执行、覆盖率分析 |
| 部署操作 | `deployer-test` / `deployer-prod` | 涉及构建、发布、环境配置 |
| 质量评估 | `eval-webapp` | 涉及评分、报告生成 |
| 方案设计 | `planner` | 架构选型、技术方案、API 设计 |
| 评审 | `reviewer` | Code Review、PR/MR 审核 |

### 边界情况处理

- **单行修复**：即使是小改动，也应分派给 Coder，而非主 Agent 亲自动手
- **紧急回滚**：通知 Deployer 执行，主 Agent 只发指令
- **信息查询**：可以自行完成（如读文件、搜索），这不属于"具体执行"
- **文件创建/删除**：属于执行动作，应分派

---

## 违规检测

在每次主 Agent 操作前，自检以下问题：

1. **这个操作是否涉及创建/修改项目文件？**
   - 是 → 必须分派给对应角色
   - 否 → 可以自主完成

2. **这个操作是否有明确的角色归属？**
   - 是 → 分派
   - 否 → 可自主完成（如通用性工作）

3. **这个操作是否属于"信息收集"类？**
   - 是（仅读取/搜索）→ 可以自主完成
   - 否（写入/执行）→ 分派

## 示例

### 正确的分派方式 ❌→✅

```
❌ 错误：主 Agent 直接写代码
   "我来帮你实现这个功能..." → 开始写 .ts 文件

✅ 正确：主 Agent 分派给 Coder
   "这个编码任务需要交给 Coder 来执行..."
   → Agent(name="coder", prompt="实现 XXX 功能...")
```

```
❌ 错误：主 Agent 亲自动手部署
   "好的，我来执行部署命令..."

✅ 正确：主 Agent 分派给 Deployer
   "部署任务交给 deployer-test..."
   → Agent(name="deployer-test", prompt="部署到测试环境...")
```
